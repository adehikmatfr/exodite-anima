# QA Context: exodite-anima

Project identity and shared rules live in `../_shared/project.md`. This file holds only QA-specific facts.

## Environments
| Environment | Purpose | Data | Deploy trigger |
|-------------|---------|------|----------------|
| Local Android emulator `flutter_avd` (verified working on 2026-09-20) | Most functional and resilience cases | Synthetic | `flutter run` or an installed debug build |

Release builds must be tested, not only debug builds: the debug and profile Android builds carry a network permission that the release build must not have (ADR-005, TC-084).

## Tools and conventions
| Need | Tool | Convention |
|------|------|-----------|
| Test runner | `flutter test` (part of the Flutter SDK; `flutter_test` is already a dev dependency) | Files under `app/test/`, named after the unit they test |
| API / contract tests | none: there is no API. The export format is the contract | Sample archives per `formatVersion`, kept with the app tests |
| E2E | Flutter's `integration_test` package (part of the Flutter SDK), plus manual device runs | Journeys only: setup, write, lock and unlock, search, export, import |
| Load / chaos | No tool chosen. Timed runs on a device with a generated journal; process-kill hooks for resilience cases | Scripts and results stored with the app tests when they exist |
| Defect tracker | Not chosen. Until one is, one markdown file per defect under `report/` | Fields from the `bug-report` skill; severity per `_shared/standards/severity-and-incident.md` |
| Mutation check | `../tools/mutate.js` once code exists | Mutants remove the lock, the encryption, and the backup exclusion; the suite must fail |

## Test data
Synthetic only: no real journal content, no real passcodes, no real names. Entries are generated by a script with known words so that searches and raw-file inspections can be checked exactly. Fixture archives for each `formatVersion`, including hostile and damaged files, are created by scripts and committed with the app tests (location to be set when the tests exist). Test passcodes are made-up.
