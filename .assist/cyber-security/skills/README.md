# skills

One folder per skill: `skills/<skill-name>/SKILL.md`.

## SKILL.md format

```
---
name: <kebab-case>
description: <when to use it, one or two sentences — this is what triggers it>
---
# <Title>
## Purpose
## When to use
## Principles
## Steps / Checklist
## Output format
## References        # links to _shared/standards/*
## Language notes    # OPTIONAL, per-language examples only
```

Keep principles language-agnostic. Reference shared standards instead of copying them.
