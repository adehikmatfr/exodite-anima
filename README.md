# exodite-anima

A private journaling app for iOS and Android. Everything you write stays on your device: no account, no server, no cloud sync. You can export your data and import it on another device.

Status: version 1 is built for Android and tested on an emulator; not released. iOS is not built yet. See `.assist/status.md` for what is done and what is not verified.

- `.assist/`: project knowledge base: roles, rules, specifications, decisions, risks, and status (start with `.assist/README.md`)
- `docs/`: end-user and contributor documentation (design drafts are moving into `.assist/`)
- `app/`: Flutter application (Android and iOS)
