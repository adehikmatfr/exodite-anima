# docs

End-user and contributor documentation for exodite-anima.

The project's specifications, decisions, risks, ADRs, threat model, test plans, and design specs live in the repository's `.assist/` folder, which is tracked and pushed with the repo. This folder is for documents written for people who use or contribute to the app, and it is not a copy of `.assist/`.

Planned here: a plain-language privacy statement, the export format specification, and guides (backup and moving to a new phone). Nothing is written yet.
