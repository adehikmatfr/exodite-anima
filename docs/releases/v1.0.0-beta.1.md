# Exodite Anima v1.0.0-beta.1 (pre-release, Android)

A free journal that keeps everything on your phone. No account, no ads, no tracking, and the app asks for no internet permission. This is an early version for testers, not a finished release.

## Which file
- `exodite-anima-v1.0.0-beta.1-arm64-v8a.apk`: most phones made in the last several years.
- `exodite-anima-v1.0.0-beta.1-armeabi-v7a.apk`: older 32-bit phones.
- Android 7.0 or newer. iOS is not available.

## Install
1. Download the file for your phone and open it. Android asks you to allow installs from this source; allow it for this install only.
2. Optional check: `SHA256SUMS.txt` lists the checksum of each file. The signing certificate's SHA-256 fingerprint is `1E:B2:78:FB:7D:62:A2:1F:ED:3E:95:36:4B:75:41:54:BB:88:72:88:E7:E1:54:3F:FE:F4:9B:93:A0:78:92:E4`. Updates will be signed with the same key.

## Please read
- **A forgotten passcode cannot be recovered.** Nobody can reset it. Use Settings, Export your journal, from time to time and keep the file somewhere you control.
- Not reviewed by an independent security reviewer yet.
- Tested on an Android emulator and on physical Android phones (Android 11 among them), not on a wide range of devices. Speed with very large journals was measured on an emulator only.
- Opening with the passcode takes a moment on purpose (it is what protects your journal); it depends on the phone.
- Screenshots and screen recording are blocked inside the app on purpose.
