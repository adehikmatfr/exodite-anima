# Exodite Anima v1.1.0-beta.1 (pre-release, Android)

A free journal that keeps everything on your phone. No account, no ads, no tracking, and the app asks for no internet permission. This is an early version for testers, not a finished release.

## What's new since v1.0.0-beta.1
- **Mood and tags**: pick a mood for an entry from a fixed 5-point scale, and add tags (from a preset list, free text, or both). Both show next to the entry in the timeline.
- **On this day**: the timeline shows a card for an entry written on the same calendar day in an earlier year, if one exists.
- **Photos**: add a photo to an entry from the camera or your photo library, with an optional caption. Photos are compressed on the way in, encrypted the same way your entries are, and travel with your entries in an export and import. There is no limit on how many photos you add.

## Which file
- `exodite-anima-v1.1.0-beta.1-arm64-v8a.apk`: most phones made in the last several years.
- `exodite-anima-v1.1.0-beta.1-armeabi-v7a.apk`: older 32-bit phones.
- Android 7.0 or newer. iOS is not available.

## Install
1. Download the file for your phone and open it. Android asks you to allow installs from this source; allow it for this install only.
2. Already on v1.0.0-beta.1? This update is signed with the same key, so it installs over it without losing your journal.
3. Optional check: `SHA256SUMS.txt` lists the checksum of each file. The signing certificate's SHA-256 fingerprint is `1E:B2:78:FB:7D:62:A2:1F:ED:3E:95:36:4B:75:41:54:BB:88:72:88:E7:E1:54:3F:FE:F4:9B:93:A0:78:92:E4`, the same as v1.0.0-beta.1. Updates will be signed with the same key.

## Please read
- **A forgotten passcode cannot be recovered.** Nobody can reset it. Use Settings, Export your journal, from time to time and keep the file somewhere you control.
- Photos keep their original embedded metadata (for example, location data a phone camera may record) as-is: nothing is stripped or asked about in this version. Keep that in mind if you share an exported photo with someone else.
- Not reviewed by an independent security reviewer yet.
- Tested on an Android emulator and at the unit/widget/format level (not yet on a physical phone for mood, tags, On this day, or photos specifically); the v1.0.0-beta.1 core (writing, lock, search, export/import) was tested on physical Android phones, including Android 11.
- Opening with the passcode takes a moment on purpose (it is what protects your journal); it depends on the phone.
- Screenshots and screen recording are blocked inside the app on purpose, including over a photo.
